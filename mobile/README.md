# Cognisphere Mobile

React Native mobile companion app for Cognisphere.

## Phase 1: Review-Only Companion

In Phase 1, the mobile app serves as a review-only companion, allowing users to:
- Review flashcards on-the-go
- Sync review progress with the desktop app
- View basic statistics

## Setup

This is a scaffolded React Native project. Full development will continue in future phases.

### Prerequisites

- Node.js 18+
- React Native development environment
- For iOS: Xcode and CocoaPods
- For Android: Android Studio and SDK

### Installation

```bash
npm install
```

### Running

```bash
# iOS
npm run ios

# Android
npm run android
```

## Future Features (Phase 2+)

- Full content browsing
- Offline mode
- Advanced statistics
- Custom study sessions
- Push notifications for reviews
